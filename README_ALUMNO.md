# Base Examen T2 Cálculo de consumo eléctrico

Las vistas ya están terminadas con Material 3. ViewBinding está habilitado y las versiones se administran desde `gradle/libs.versions.toml`. Complete los `TODO` de Kotlin: SQLiteOpenHelper y CRUD, validación y cálculo, RecyclerView/CardView y swipe.

## Organización del código

```text
com.cibertec.electricidad
├── MainActivity
├── adapter/ConsumoAdapter
├── data/ConsumoHelper
├── model/Consumo
└── ui/RegistroFragment, ConsumosActivity y ConsumosFragment
```

Abra la carpeta raíz en Android Studio. Si solicita Gradle JDK, seleccione el JDK integrado de Android Studio; es un ajuste local que no se incluye en el ZIP.
